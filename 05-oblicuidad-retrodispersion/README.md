# Oblicuidad del sensor y retrodispersión

Visualización interactiva simplificada para explicar cómo el ángulo de incidencia, el alcance oblicuo, el ground range, el swath y la incidencia local influyen en la retrodispersión SAR sobre una superficie hipotética.

## Uso

Con el servidor local activo, abre:

`http://127.0.0.1:8000/05-oblicuidad-retrodispersion/`

La página acepta parámetros opcionales:

- `?incidencia=25&pendiente=0`
- `?incidencia=55&pendiente=-15`
- `?incidencia=40&pendiente=12`
