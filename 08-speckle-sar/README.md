# Speckle en imágenes SAR

Visualización simple para explicar qué genera el speckle en una imagen SAR.

La escena muestra:

- una celda de resolución con varios dispersores;
- ecos que regresan con fases distintas;
- suma coherente constructiva, destructiva o parcial;
- el brillo resultante en una imagen SAR granulada.
