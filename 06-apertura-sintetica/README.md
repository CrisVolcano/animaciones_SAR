# 06 · Apertura sintética

Visualización didáctica para explicar cómo el movimiento de una antena SAR permite observar el mismo blanco desde múltiples posiciones y sintetizar una apertura virtual.

## Controles

- Longitud física de antena `La`.
- Distancia al blanco `R0`.
- Banda X, C o L para modificar `λ`.
- Secuencia conceptual: antena, movimiento, observaciones, síntesis y comparación.
- Recorrido manual, demo y pausa.

## Relaciones mostradas

```text
β ≈ λ / La
LSA ≈ β · R0
δaz,SAR ≈ La / 2
```

La geometría de la animación está exagerada deliberadamente para fines didácticos y no debe interpretarse como un dibujo a escala.
