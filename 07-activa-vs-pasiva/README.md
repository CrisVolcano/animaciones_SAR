# Teledetección activa vs pasiva

Animación comparativa entre sensores pasivos y activos.

La escena muestra dos sensores observando una misma superficie:

- el sensor pasivo recibe energía natural reflejada o emitida;
- el sensor activo emite su propio pulso y mide el eco de retorno;
- el ciclo día/noche y la nube permiten contrastar la dependencia de condiciones externas.
