# Tipos de polarización electromagnética

Visualización interactiva para distinguir polarización lineal, circular y elíptica a partir de la trayectoria de la punta del campo eléctrico.

## Uso

Con el servidor local activo, abre:

`http://127.0.0.1:8000/04-tipos-polarizacion/`

La página también acepta parámetros opcionales:

- `?tipo=lineal&plano=vertical`
- `?tipo=circular&giro=right`
- `?tipo=eliptica&giro=left`
